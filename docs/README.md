# Documentação do projeto

Qualidade e apresentação de radiografias de tórax e erros, calibração e generalização de classificadores de pneumonia.

**Para entender o projeto, leia nesta ordem:**

1. `trajetoria.md` — como o projeto chegou até aqui, passo a passo.
2. `01_problema_e_hipotese.md` — a pergunta, a hipótese testável e o critério de sucesso.
3. `02_auditoria_dos_dados.md` — as três bases lado a lado.
4. `decisoes.md` — todas as decisões, por fase, base e tema.

**Detalhes:**

| Pasta ou arquivo | Conteúdo |
|---|---|
| `fundamentacao/` | Física, aquisição, geometria, processamento e qualidade da radiografia (1A a 1F) |
| `escolha_das_bases.md` | Por que estas bases foram escolhidas |
| `auditorias/` | Uma auditoria preliminar e uma final por base |
| `protocolo/` | Protocolo científico v1.0 e plano de execução |

**Regra:** cada etapa tem um documento só. Versões novas substituem as antigas no mesmo arquivo; o histórico fica no git.
